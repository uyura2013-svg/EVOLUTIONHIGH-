# EvolutionHigh

Мобильный 3D FPS-проект на Godot 4. Это самостоятельная игра с оригинальными ресурсами и механиками жанра tactical FPS; закрытые файлы Standoff 2 не используются.

## Сейчас в проекте
- 3D арена, игрок от первого лица и базовое управление.
- Стрельба, перезарядка и тренировочный бот.
- HUD с HP, патронами и счётом.
- Сенсорные кнопки для Android и клавиатура для тестирования.
- GitHub Actions для проверки проекта и попытки Android export.

## Сборка
Откройте проект в Godot 4.4+ и запустите `scenes/main.tscn`.
Android export preset: `Android`. APK появится как артефакт workflow только если экспорт завершится успешно.

Это ранняя игровая основа, а не готовая полноценная игра или копия Standoff 2.
